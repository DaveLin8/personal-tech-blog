I'm Dave Lin. I started this blog to document what I build, what breaks, and how I get it working again. I write about self-hosted AI, Linux, and the tools I use to run services from home.

[Find me on LinkedIn](https://www.linkedin.com/in/davedlin/).

I run Qwen locally with Ollama and Open WebUI, and I experiment with video generation in ComfyUI. This blog is part of the same setup. Hugo builds the pages, Jenkins deploys them, and an AWS EC2 instance serves them over HTTPS through a WireGuard tunnel to my home server.

If you're new here, start with [how I built the AI server](/posts/building-my-own-ai-server/) or [how I deployed this blog](/posts/hugo-behind-aws-ec2-and-wireguard/).
